# Аналитика предприятий (Radar4Promote)

Веб-приложение для просмотра предприятий на карте, поиска и анализа данных.

## Запуск

Нужен Node.js 20 или новее.

1. Скопируйте `.env.example` в `.env`.
2. Укажите логин и пароль администратора. Сгенерируйте ключ шифрования:

   ```sh
   node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))"
   ```

   Сохраните его в `RADAR_ENCRYPTION_KEY`. Не публикуйте `.env`.
3. Установите зависимости и запустите сервер:

   ```sh
   npm install
   npm start
   ```

   В PowerShell используйте `npm.cmd`. Откройте http://127.0.0.1:8000.
4. При первом входе настройте приложение-аутентификатор и сохраните резервные коды.

Не открывайте `public/index.html` напрямую и не используйте статический сервер: вход защищает сервер приложения. Для сетевого доступа нужны HTTPS и согласование с ИТ/ИБ.

## Что внутри

- Карта объектов OpenStreetMap, фильтры, тепловой слой, графики и экспорт CSV.
- Вход по паролю и TOTP-коду. Поддерживается одна локальная учётная запись.
- Резервный набор точек хранится в `public/data/osm-cache.json`.
- CSV можно использовать для загрузки реквизитов ФНС. Полный реестр ФНС не загружается автоматически; OSM не подтверждает ИНН или статус клиента.

## Структура

- `public/` — страницы, стили, скрипты и данные приложения.
- `server.js`, `server/` — HTTP-сервер и авторизация.
- `tests/`, `tests/fixtures/` — тесты и тестовые данные.
- `docs/` — презентация проекта.
